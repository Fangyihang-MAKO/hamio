安卓手机怎么开始？+
  1. 下载 APK，并允许当前浏览器安装此应用
  2. 打开 Ha!mio，按提示允许“显示在其他应用上层”
  3. 想让她对正在使用的应用做出反应，再开启使用情况访问权限

如果微信内无法下载，请从右上角菜单选择“在浏览器打开”后重试

锁屏之后，她不见了怎么办？+

通常是手机限制了后台运行。请在系统设置里允许 Ha!mio 自启动、后台运行，并将电池策略设为“不限制”。不同机型的入口名称会有差异

华为：设置 → 应用和服务 → 应用启动管理 → Ha!mio → 关闭自动管理，并允许三项后台权限

查看各品牌锁屏恢复图解

纯血鸿蒙通过兼容工具运行时，仍可能消失，也无法完整识别鸿蒙原生应用

电脑版怎么操作？+

打开 EXE 即可使用，系统需有 .NET Framework 4.8。单击害羞、双击聊天、拖动换位置，拖到左右边缘松手即可探头。更多功能在右键菜单里

更新前请先从旧版的右键或托盘菜单中退出。电脑版目前不支持识别前台应用后自动躲起

当前为未签名的个人体验版，请确认文件来源，不要关闭系统安全防护

AI 聊天需要付费吗？密钥填在哪里？+

AI 聊天使用你自己的模型服务账户余额，费用由对应服务商收取。网页不会索取或保存你的密钥

安卓：消息 → 对应角色 → 更多 → 填写密钥
电脑：聊天窗口 → 装扮与密钥

当前程序使用 DeepSeek 兼容的既有接口，仅填写其他平台的密钥不能更换服务商。聊天内容会发送给模型服务处理，密钥在本机加密保存

支持 iPhone 吗？两个版本能同步吗？+

目前提供 Android 和 Windows 两个版本，暂不支持 iPhone。聊天记录、密钥和设置保存在各自设备上，不会跨设备同步
