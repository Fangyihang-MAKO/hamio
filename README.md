# Ha!mio

Ha!mio 下载网站的静态文件，包含 Android 与 Windows 安装包、角色图片和使用指南。

## 发布到 GitHub Pages

1. 将本目录内的所有文件上传到 GitHub 仓库的 `main` 分支根目录，保留 `assets` 和 `downloads` 子目录。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 **main** 和 **/ (root)**，点击 **Save**。
5. 等待 Pages 发布完成，使用页面显示的 `github.io` 网址访问。

无需构建或安装依赖，`.nojekyll` 用于直接发布静态文件。图片和下载链接均使用相对路径，支持仓库子路径。

## 文件说明

- `index.html`：页面内容
- `style.css`：页面样式
- `app.js`：流萤动画和页面交互
- `assets/`：页面图片
- `downloads/`：安装包及 `SHA256SUMS.txt` 校验文件

网站当前提供 Ha!mio 流萤 1.1.4（Android APK 与 Windows EXE），以及虚照 Android 0.3.1 / Windows 0.3.0 双形态版，与 Skill MVP 体验包分开。安装包内容与本地交付版一致，SHA-256 见 downloads/SHA256SUMS.txt。流萤 Windows 便携 ZIP 包含同一 EXE 和使用说明。

虚照入口位于首页 `#xuzhao`。电脑版支持 Windows 10 / 11 x64，依赖 .NET Framework 4.8；安卓版支持 Android 8.0 及以上。0.3.0 增加「二维马老师 ↔ 星神★阿哈」形态切换，每种形态包含 12 张角色画稿。二维马老师保留深蓝紫星夜画室；阿哈采用酒红渐变、笑脸多边形爱心与红色弯月。切换会更新人物、当前表情头像、界面与后续聊天人设，选择在重启后保留。

两种形态是同一个虚照，在同一设备上共用密钥、聊天、设置和待办；历史回复保留原来的头像与形态。切换时若正在生成回复，会停止请求并保留用户消息，可按当前形态重试。虚照与流萤仍使用独立的本机记录，Android 与 Windows 不跨设备同步。保留摸头喂食、鼓掌、左右探头、扑腾、聊天快捷入口及本地待办提醒。电脑版保留 1.2 倍扑腾动作频率，不表示显示器帧率提高；尚未实现前台应用识别。AI 聊天需用户自己的密钥及账户余额。公开文件包括 APK、EXE 及展示图，不发布源代码包。

Android 0.3.1 为二维马老师增加身后四芒星，为星神★阿哈增加笑脸多边形爱心与红弯月，站立和左右探头均有少量装饰。探头转角和上下浮动幅度为上一版的 1.2 倍，动作周期不变。角色原图、聊天人设和电脑版保持原样。

升级虚照安卓版时直接覆盖安装，不要先卸载以免删除本机数据；已核对 0.3.1、0.3.0 与 0.2.2 的签名证书相同。电脑版先从旧版托盘退出，再打开新版，沿用虚照已有存档。安卓在「装扮 → 当前形态」切换；电脑在「装扮与密钥 → 形态切换」、人物右键或托盘菜单中切换。

网页中的流萤、虚照均可点击摸头、切换害羞表情并恢复日常，使用各自的手写台词。晃动开关独立，支持系统减少动画设置，页面隐藏或角色滚出视野时暂停动画。网页预览不调用 AI，也不会读取或修改桌宠应用记录。

虚照 Android 0.3.1 仍为开发证书签名的个人预览 debug 构建（应用 ID `dev.hamio.xuzhao`，版本代码 3）。2026-10-22 的交付记录为：离线编译成功，172 项单元测试通过，lint 为 0 错误、30 警告；包名、签名及最低系统版本已核实。尚未进行安卓真机或模拟器安装、覆盖升级后的实际数据、后台兼容性或真实模型请求验收，不代表应用商店正式发行。

本仓库仅放置面向访客公开的网页资源，不包含桌宠开发源码、API 密钥或聊天记录。流萤角色来自《崩坏：星穹铁道》，相关角色与作品权利归原权利方所有；本项目为非官方同人作品。

点击安装包下载后，对应下载区会显示可选的「去 GitHub 点个 Star」链接；导航和页脚也提供仓库入口。网页不会自动登录或自动 Star，下载无需先 Star。

## 角色创作间（界面体验版）

`studio/` 提供四步交互：选择 Q 版形象、设计与重做姿态、通过提示词完善角色人设、在模拟桌面里试养。
本版尚未接入图片生成服务，没有真正绘图或 AI 聊天；示例使用现有流萤素材并明确标注，上传的图片在浏览器内处理和保存，不会自动发送到服务器。
每个姿态可添加姿势参考、填写修改备注或手动导入成品图片，并保留最近 4 个旧版本供并排比较和恢复。服务未接入时，重做操作会提示不可用并保留原图。
人设页支持性格、关系、说话习惯、共同经历和台词示例，手动填写后在本地整理成可复制的提示词。AI 完善接口已预留，默认不调用模型。
试养可为点击、拖动、模拟工作、模拟休息分别映射图片，体验靠左或靠右工作、休息和恢复日常，也可调整大小、不透明度和晃动幅度。缺少对应图片时有明确提示，气泡只展示手写开场白；这是网页内的静态姿态与轻晃模拟，不会悬浮到其他应用上，也不会监测真实工作状态。

编辑进度通过 IndexedDB 自动保存在本地，尚未确认形象或只有文字时也可恢复。同一浏览器、同一网站来源（协议、域名和端口）保留一份草稿，不按路径隔离，也不跨浏览器或设备同步。请等页顶显示「已自动保存」再离开，或点击「立即保存」并等到成功；清理浏览器数据会丢失草稿，请定期导出备份。

完整设计 JSON 使用 `schemaVersion: 4`，包含候选图、姿态参考、修改备注、当前姿态与最近 4 个旧版本、人设、提示词和互动映射等试养设置；兼容导入版本 1、2、3。确认基础形象后可导出，下次通过页顶「导入设计」恢复；提示词 TXT 也可单独下载。导出的记录不是桌宠安装包，也不代表生成了新图片。现有 Android、Windows 安装包保持不变。
接口约定与接入位置见 [studio/README.md](studio/README.md)。
